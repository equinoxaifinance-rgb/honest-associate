How this stays honest (the machinery)

In 2023, lawyers were sanctioned for filing a brief of cases ChatGPT invented. This agent is built so that cannot happen — not because the model promises, but because the system checks:

Bounded corpusReal published opinions from CourtListener in a Sanity dataset. The banner above is written by a census script from measured values — never typed by hand.
Mechanical quote checkEvery claim must carry a verbatim quote. Code — not the model — verifies it exists letter-for-letter in both the text the model was shown and the stored opinion. Failures are rejected and stripped.
Withheld summariesIf zero claims survive verification, no summary is shown. An unsupported answer never wears this tool's credibility.
Server-truth labelsCase names, dates, courts, and links come from the database record — the model cannot invent a URL or mislabel a case.
Honest edges"Not in corpus" means not in THIS collection, never that no authority exists. Gaps say what the corpus can't answer; truncation is disclosed per answer.
Ablation, 50 runs per arm, same model/prompt/evidence — enforcement OFF: 18 fabricated quotes shipped (11/50 runs dirty). Enforcement ON: 0.

Try it yourself: the verify tab's "infamous fake case" chip is Varghese v. China Southern Airlines — the actual fabricated case from the sanctions story. Every AI chatbot will summarize it for you. This one structurally can't.

Grades: DIRECT_QUOTE = the quote itself answers · SUPPORTED = fair paraphrase, quote shown · RELATED = adjacent context, not the answer.
